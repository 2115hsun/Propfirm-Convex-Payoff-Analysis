# docs

Open this folder as an Obsidian vault (Open folder as vault). Start at `Home.md`.

Suggested community plugins: Dataview (live tables on Home), Templater or core Templates (point the template folder to `Templates/`), Obsidian Git (commit and push notes).

Commit `.obsidian/` only if you want collaborators to get the same settings; otherwise add `docs/.obsidian/workspace*` to `.gitignore`.
